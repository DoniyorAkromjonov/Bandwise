# Bandwise Listening audio

These three short practice recordings use original scripts written for this project. The audio was synthesized locally with the Microsoft Zira English voice installed on Windows. The corresponding timestamped transcripts live in `src/data/listening-cues/`; `tools/generate-listening-audio.ps1` recreates the WAV files from the scripts.

The voice is a Microsoft system voice. Any redistribution or reuse of generated recordings must follow the applicable Microsoft voice and Windows license terms.
